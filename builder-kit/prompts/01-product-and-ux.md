# 01 — Product Discovery and UX Prompt

Read README.md, docs/01-product-vision.md, docs/02-learning-experience.md, docs/03-curriculum-map.md and the source curriculum before design.

Act as a senior UX researcher and learning experience architect. Do not code yet.

## Tasks
1. Define primary learner persona and highest-priority jobs-to-be-done.
2. Draw the sitemap and navigation hierarchy.
3. Define journeys:
   - first visit → choose learning goal → course map → first lesson;
   - dashboard → continue course → lab → checkpoint → feedback;
   - missed question → review queue → retry → mastery evidence;
   - project → milestone → rubric → reflection.
4. Specify each screen's purpose, primary action, secondary actions and content hierarchy.
5. Define all states: first-time/empty, loading, success, incorrect answer, unavailable content, network error, completed course, mobile menu.
6. Create desktop, tablet and mobile wireframes. Include Arabic RTL and English LTR edge cases.
7. Define a usability test script for five representative learners. Focus on whether they can find the next learning action and complete the first AIB-100 activity.
8. Map each UX element to a product requirement and label any proposed addition.

## Output
Sitemap, user flow diagrams, screen inventory, text wireframes, state matrix, mobile behavior, accessibility checklist, usability script, unresolved questions. Stop before implementation.
