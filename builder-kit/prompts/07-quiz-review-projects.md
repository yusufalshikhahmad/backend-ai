# 07 — Quiz, Review and Project Prompt

## Quiz
Support single choice, multiple select, ordering/matching where accessible, and short answer with a rubric or manual review. Every question contains explanation, hint 1, hint 2, skill tags, difficulty and source reference. Never expose answer before submit. Distinguish incorrect, partially correct and correct.

## Review
Create a simple spaced-review queue based on actual missed concepts and successful recall. Due-date scheduling should be transparent and configurable. Do not claim scientifically optimized adaptation; describe it as a starter scheduling heuristic until evaluated.

## Projects
Show project brief, goals, prerequisites, deliverables, milestones, rubric, submission checklist and reflection. Use source-derived project requirements only when verified. The UI can prototype submission locally but must not claim cloud storage.

## Acceptance
Answer state survives navigation in prototype; rationales are readable; keyboard/screen-reader labels; no trick wording; review only contains items with actual learner history or clearly labelled demo data.
