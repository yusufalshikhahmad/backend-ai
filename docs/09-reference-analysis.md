# Reference Analysis — Prompt-first UI

## Screenshot analysis
The reference is a focused dark landing page: small announcement capsule, centered headline, oversized prompt composer with controls in its footer, suggestion chips, generous whitespace, few distractions, and a subtle multicolor border around the main input.

## Patterns to adapt (not copy branding)
- Prompt-first entry: turn an empty page into a concrete learning intent.
- Progressive disclosure: optional controls stay in the composer footer.
- Suggestion chips: communicate possibilities and lower friction.
- Calm hierarchy: headline → composer → chips → supporting content.
- Highlight the main interactive surface only; don't glow every card.
- Whitespace makes the first action feel clear.

## Avoid
Don't copy logos, name, exact brand assets, or text. Don't use chat UI as the whole LMS. Avoid excessive gradients/neon, low-contrast gray, decorative controls with no behavior, fake statistics, and dense dashboard KPI walls.
