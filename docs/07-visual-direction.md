# Visual Direction & Image Prompt Pack

## Art direction
Modern engineering studio + interactive academy. Avoid childish gamification and generic AI neon clichés. Premium, clear, calm technical aesthetic: dark graphite or warm light canvas, cyan/indigo accents, subtle grids, diagrams, high-quality illustrations. Strong Arabic type; technical monospace for code.

## Initial visual tokens (exploratory)
Ink background #101522; surface #1B2333; cyan #43D9F5; violet #8B7CFF; green #46C98A; amber warning. Evaluate contrast; light mode too. Typography candidates: IBM Plex Sans Arabic or Noto Sans Arabic, Inter, JetBrains Mono. Spacing 4/8pt rhythm; radius 12–20px. Reduced motion option.

## Screens
1. Landing hero: “تعلم هندسة الذكاء الاصطناعي ببناء أنظمة حقيقية” and journey illustration.
2. Learning map: semesters, prerequisite links, milestones.
3. Dashboard: today's 20–30 minute plan, reviews due, continue learning, project.
4. Lesson player: content + visual + interactive panel + step navigation.
5. Terminal simulator: shell, history, safe simulated filesystem, hints.
6. Quiz: one question, confidence optional, explanatory feedback.
7. Project workspace: milestones, rubric, checklist, submission and reflection.
8. Study room (later): shared board and moderated discussion.

## Image prompt template
Create a polished editorial illustration for an adult technical learning platform. Subject: [SUBJECT]. Minimal 3D/isometric or clean vector hybrid, graphite backdrop with cyan and violet accents, soft studio lighting, fine grid, uncluttered premium developer-tool aesthetic, no text, no logo, no watermark, 16:9. Make it technically plausible and visually explanatory. Supply accessible alt text separately.

## Example prompts
Hero: visual journey linking terminal, Python modules, data pipeline, neural network, API gateway, database and deployment containers.
RAG: document pages split into chunks, vector points, three retrieved passages highlighted flowing into answer with source markers.
Agents: planner connected to search, calculator, database and code-review tools; transparent step timeline, not a robot character.
Linux: elegant terminal workbench with prompt, directory tree and Python file cards; no readable labels.
Deep learning: layered network showing forward activations and backward gradients, clean educational schematic.

## Asset workflow
Track prompt, alt text, aspect ratio, source/license, generated revision. Optimize, lazy-load. Diagrams that teach should be accurate—not decorative art.
