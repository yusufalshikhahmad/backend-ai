## Interactive lesson ideas (design additions)
- Linux/Python: terminal simulator، code tracing، debugging.
- Math: visual vectors/graphs، sliders، formula intuition.
- Data: pipeline visualization and data-quality detective.
- ML: decision boundary، metrics tradeoffs.
- Deep learning: neuron/backprop visualization، tensor shape playground.
- Transformers: tokenization/attention visualization (label as illustrative when not computed).
- FastAPI: request lifecycle sequence.
- RAG: chunking and retrieval playground over toy corpus with source markers.
- Agents/MCP: tool-routing sandbox and trace.
- Serving: latency/throughput/VRAM estimator with assumptions.
- MLOps: pipeline DAG and failure simulation.
- Security: threat scenarios and defensive exercises.
- Capstone: proposal → architecture → milestones → test plan → demo → reflection.
