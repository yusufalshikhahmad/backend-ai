# Visual Screen Specification

## 1 Home — prompt-first
Minimal nav: brand, courses, labs, projects, community, dashboard, account. Optional announcement pill. Large hero heading and short supporting line. Prompt composer (2–3 lines) with footer selector, attachment/reference affordance (only if functional), CTA. Five suggestion chips. Below fold: continue learning, weekly plan, review queue, three feature cards.
Mobile: compact header, headline 32–38px, composer full-width, controls wrap, chips horizontal scroll, cards stacked.

## 2 Student dashboard
Greeting and today's goal. Dominant Continue course card with module, lesson, progress, CTA. Secondary: review due, project milestone, minutes plan. Course journey overview. Avoid vanity charts.

## 3 Course map
Semesters/modules; prerequisite arrows; status: not started, learning, practiced, mastered. Active node highlighted. Locked course explains prerequisite. Provide accessible list alternative.

## 4 Lesson player
Top breadcrumb/course/module/progress/save. Reading column: outcome, explanation, example. Wide desktop interaction/diagram column. Bottom previous/next/checkpoint. Mobile stacks and interaction can expand.

## 5 Interactive lab
Task goal, simulated terminal or diagram canvas, run button, result/output, hint ladder, reset/history. No arbitrary code execution in MVP.

## 6 Checkpoint
One question at a time; optional confidence; hint; submit; feedback with reasoning/misconception; retry and recommended review. Manage focus when feedback appears.

## 7 Project workspace
Milestones, deliverables, checklist, rubric, feedback, artifact links and reflection. Visual progress from stages, not vanity percentage.

## 8 AI Tutor (later)
Lesson context chip, mode selector (hint/explain/quiz/debug), cited sources, quick follow-ups. Mobile sheet must not hide lesson context.

Every screen must specify loading, empty, error/retry, success, disabled, hover, keyboard focus, active, selected, mobile, RTL, LTR and reduced motion.
